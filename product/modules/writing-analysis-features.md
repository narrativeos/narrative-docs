# 写作分析特性 Writing Analysis Features

> 本文档为 NarrativeOS 分析引擎的写作分析子模块，面向作者、编辑和内容创作者，提供全面的文本诊断与叙事分析能力。

## 摘要

写作分析模块提供从微观语言诊断到宏观叙事结构分析的全栈能力，帮助作者提升写作质量、发现潜在问题、优化故事结构。

## 目标用户

- 小说作者与网络文学创作者
- 剧本创作者与编剧
- 内容编辑与文学编辑
- 创意写作课程教师与学生

## 能力分类

写作分析特性分为五大类：

1. **文本诊断** — 语言层面的问题检测
2. **统计分析** — 量化写作特征
3. **内容分析** — 敏感内容与风格检测
4. **叙事分析** — 故事结构与元素分析
5. **评估建议** — 综合评估与改进建议

---

## 一、文本诊断 Text Diagnostics

### 拼写错误查找器 Misspellings Finder

检测文本中的拼写错误并提供修正建议。

- **功能**：自动识别拼写错误，区分专有名词与通用词汇
- **输出**：错误位置、建议修正、置信度评分
- **场景**：初稿校对、多语言文档审查

### 陈词滥调查找器 Cliché Finder

识别文本中的陈词滥调和过度使用的表达。

- **功能**：基于语料库检测常见陈词滥调短语
- **输出**：匹配短语、位置、替代表达建议
- **场景**：创意写作优化、学术写作去套路化

### 重复短语检测 Repetitive Phrases

发现文本中重复出现的短语模式。

- **功能**：检测2-5词范围内的重复短语序列
- **输出**：重复短语列表、出现频率、位置索引
- **场景**：文风多样化、减少语言单调性

### 副词重复使用检测 Repeated Use of Adverbs

识别过度使用或重复使用的副词。

- **功能**：统计副词使用频率，标记重复项
- **输出**：副词频率排行、重复位置、精简建议
- **场景**：精简写作、强化动词表达

### 形容词重复使用检测 Repeated Use of Adjectives

识别过度使用或重复使用的形容词。

- **功能**：统计形容词使用频率，标记重复项
- **输出**：形容词频率排行、重复位置、替代表达
- **场景**：丰富描写、避免语言贫乏

## 二、统计分析 Statistical Analysis

### 句子统计与可用性评分 Sentence Stats & Usability Score

提供文本的量化统计与可读性评估。

- **句子统计**：
  - 总句数、平均句长
  - 句子长度分布
  - 复杂句/简单句比例
- **可用性评分**：
  - 基于 Flesch Reading Ease 等算法
  - 适配目标读者群体的可读性评分
  - 难度等级建议

### 对话与叙事比例 Dialogue vs. Narrative Usage

分析文本中对话与叙事内容的比例分布。

- **功能**：自动区分对话段落与叙事段落
- **输出**：
  - 对话占比 vs 叙事占比
  - 章节级分布图
  - 平衡性建议
- **场景**：小说写作、剧本分析、叙事节奏优化

---

## 三、内容分析 Content Analysis

### 显式语言查找器 Explicit Language Finder

检测文本中的显式/敏感语言。

- **功能**：识别粗俗语言、诅咒词、敏感表达
- **输出**：匹配词汇、位置、严重程度分级
- **场景**：年龄分级、内容合规审查

### 显式内容分析 Explicit Content Analysis

更全面的内容敏感性分析。

- **功能**：
  - 暴力内容检测
  - 性相关内容检测
  - 仇恨言论检测
  - 年龄适宜性评估
- **输出**：内容分级、风险标记、位置索引
- **场景**：出版审查、平台合规、内容分级

---

## 四、叙事分析 Narrative Analysis

### 情节分析 Plot Analysis

分析故事的主线与支线情节结构。

- **功能**：
  - 情节线识别与提取
  - 主线/支线关系映射
  - 情节完整性评估
- **输出**：情节线图、完整性评分、缺失环节标记

### 叙事弧线分析 Narrative Arc Analysis

分析故事的叙事弧线结构。

- **功能**：
  - 识别经典叙事弧线（英雄之旅、三幕剧等）
  - 情节点定位（激励事件、转折点、高潮）
  - 弧线完整性与有效性评估
- **输出**：弧线图、情节点列表、结构建议

### 故事元素分析 Story Elements Analysis

分析故事的核心组成元素。

- **功能**：
  - 角色、场景、道具识别
  - 元素关联关系图谱
  - 元素使用频率与平衡性
- **输出**：元素清单、关系图、平衡性报告

### 节奏分析 Pacing Analysis

分析叙事的节奏分布与变化。

- **功能**：
  - 场景长度与密度分析
  - 紧张度曲线绘制
  - 节奏变化点识别
- **输出**：节奏曲线图、节奏问题标记、调整建议

### 角色分析 Character Analysis

分析故事中角色的特征与发展。

- **功能**：
  - 角色出场频率统计
  - 角色对话比例分析
  - 角色弧线与成长轨迹
  - 角色关系图谱
- **输出**：角色档案、关系图、发展轨迹图

### 冲突分析 Conflict Analysis

识别和分析故事中的冲突。

- **功能**：
  - 内部冲突 vs 外部冲突识别
  - 冲突强度与频率分析
  - 冲突解决路径追踪
- **输出**：冲突类型分布、强度曲线、解决状态

### 主题分析 Theme Analysis

识别和分析故事的核心主题。

- **功能**：
  - 主题关键词提取
  - 主题重复与强化模式
  - 主题一致性评估
- **输出**：主题列表、主题强度图、一致性评分

### 故事结构指南 Story Structure Guide

提供故事结构的分析与改进建议。

- **功能**：
  - 经典结构模型匹配（三幕剧、英雄之旅等）
  - 结构完整性检查
  - 结构优化建议
- **输出**：结构匹配报告、改进建议清单

## 五、评估建议 Assessment & Recommendations

### 总体评估 Overall Assessment

提供文本的综合质量评估。

- **维度**：
  - 语言质量
  - 叙事结构
  - 角色塑造
  - 主题深度
  - 节奏控制
- **输出**：综合评分、维度雷达图、总体评语

### 关键建议 Key Recommendations

基于分析结果生成的优先改进建议。

- **功能**：
  - 按优先级排序的建议列表
  - 每个建议附带具体位置与修改示例
  - 预期改善效果预估
- **输出**：建议清单、优先级标记、修改指引

### 不一致性与需重新审视项目 Inconsistencies and Items to Revisit

检测文本中的不一致与潜在问题。

- **功能**：
  - 事实一致性检查（时间、地点、角色特征）
  - 情节漏洞检测
  - 前后矛盾识别
  - 未解决伏笔标记
- **输出**：问题清单、位置索引、严重等级

### 最终审查清单 Final Review Checklist

提供发布前的最终检查清单。

- **检查项**：
  - [ ] 拼写与语法错误已修正
  - [ ] 陈词滥调已替换
  - [ ] 重复表达已精简
  - [ ] 对话与叙事比例平衡
  - [ ] 叙事弧线完整
  - [ ] 角色发展合理
  - [ ] 冲突有效解决
  - [ ] 主题一致性强
  - [ ] 节奏流畅
  - [ ] 内容合规性通过
- **输出**：可勾选清单、通过/不通过状态、遗留问题标记

## 典型使用场景

### 场景一：初稿诊断

> 作者完成小说初稿后，导入系统获得全面诊断报告：
> - 发现 23 处陈词滥调表达并推荐替换方案
> - 检测到处 15 处重复使用的副词
> - 揭示对话与叙事比例失衡（对话占比仅 15%）
> - 标记 3 个角色发展不完整的警告

### 场景二：结构优化

> 作者对故事结构不满意，系统分析显示：
> - 第二幕节奏明显拖沓（紧张度曲线平缓）
> - 激励事件位置偏后（在第 25% 而非推荐的 10-15%）
> - 主题"孤独"在前两幕强化充分，但第三幕减弱
> - 建议：压缩第二幕中间 3 章，提前激励事件

### 场景三：出版前审查

> 编辑在提交出版社前执行最终审查清单：
> - 自动检查所有必检项
> - 发现 2 处时间线不一致（角色年龄矛盾）
> - 确认内容分级为 PG-13，符合目标市场
> - 生成可附交出版社的分析摘要报告

## 使用方式 How to Use

```text
1. 导入待分析文本（支持 Markdown / TXT / DOCX / EPUB）
2. 选择分析维度（全部或指定类别）
3. 执行分析并查看可视化报告
4. 根据优先级建议进行修订
5. 重新分析验证改进效果
6. 导出最终审查报告
```

## 与产品矩阵的关系

写作分析特性是 NarrativeOS 分析引擎的核心应用模块，通过以下产品交付：

- **LibreOffice/Word 插件端**：提供文本诊断类能力（拼写检查、陈词滥调、重复表达检测）
- **NarrativeStudio**：提供叙事分析类能力（情节、弧线、角色、冲突、主题、节奏分析）
